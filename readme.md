# Jefferson Santa Rosa | Site Oficial

Este repositório contém o site institucional de Jefferson Santa Rosa, desenvolvido em HTML, CSS e JavaScript puro, com múltiplas páginas e identidade visual voltada para palco, cultura pernambucana, Carnaval e música popular.

## Visão geral

O projeto apresenta:

- página inicial com hero visual e chamadas de ação;
- seção de apresentação do artista;
- história e trajetória em linha do tempo;
- catálogo de músicas e composições;
- agenda de shows e histórico de apresentações;
- galeria de fotos;
- formulário de contato e links externos;
- layout responsivo e acessível.

## Como abrir o site

Não há build nem dependência de instalação.

### Opção 1
Abra diretamente o arquivo [index (14).html](index%20(14).html) no navegador.

### Opção 2
Use o Live Server no VS Code:

1. abra a pasta do projeto;
2. clique com o botão direito em [index (14).html](index%20(14).html);
3. escolha "Open with Live Server".

A estética do site usa:

- fundo preto e quase preto como base;
- tons dourados como marca visual principal;
